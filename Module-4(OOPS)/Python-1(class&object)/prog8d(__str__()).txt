__str__()    method
-----------------------
1) What  does  __str__()  method  do  ?  ---> Concatenates  all  the  values  of  the  object  to  form  a  string  and  returns  string

2) How  to  concatenate  values  of  the  object  ?  ---> With  F  string

3) Let  object  have  25 , 10.8  and  True,
    what  does   __str__()  method  do ?  --->  Returns  '25<tab>10.8<tab>True'

4) In  other  words,  __str__()  method  converts  object  to  string

5) How  is  __str__()  method  different  from  __dict__ ?  --->  __str__()  is  a  string  representation  of  the  object  and
												       __dict__  is   a  dictionary  representation  of  the  object

6) What  is  special  about  __str__()  method ?  --->  It  is  automatically  executed  when  object  is  being  printed

7) What  does  print(object)  do ? --->  Executes  __str__()  method  of  class

8) print(object)
    What  is  printed ?  --->  That  string  which  is   returned  by   __str__()  method

9) Finally  print(object)  becomes  print(string)

10) Can  __str__()  method  be  called  explicitly ?  --->  Yes  with  object . __str__()

11) What  is  the  result  of  object . __str__() ?  --->  The  string  returned  by  __str__()  method

12) Can  __str__()  method  return  non-string ?  ---> Yes  when  it  is  called  explicitly  and
                                                                                     no  when  it  is  executed  automatically

13) Can  __str__()  method  have  arguments  ?  --->  Yes  when  it  is  called  explicitly  and
                                                                                     no  when  it  is  executed  automatically

14) What  does  print(object)  do  when  class  does  not  have  __str__()  method ?  --->
													Executes  __str__()  method  of  object  class

15) What  does  __str__()  method  of  object  class  do  ?  --->  Returns  type  and  address  of  the  object

16) Therefore  print(object)  prints  type  and  address  of  the  object  when  the  class  does  not  have  __str__()  method

17) What  is  special  about  object  class ?  --->  It  is  the  default  parent  class  to  all  python  classes
									     (user  defined  and  pre-defined  classes)

18) Where  is  object  class  defined ?  ---> In  builtins  module
