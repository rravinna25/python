Private  instance  variable
------------------------------
1) How  is  private  instance  variable  denoted ?  --->  With  __  (Double  underscore  but  not  single  underscore)

2) What  is  the  name  of  private  instance  variable ?  --->  __variable 

3) class  c1:
           def  m1(self):
	         self . __x = 10
    What  is  __x   called ?  ---> Private  instance  variable  due  to  __

4) To  whom  is  private  instance  variable  visible ?  ---> All  the  methods  of  same  class
    From  whom  is  private  instance  variable  hidden  ?  ---> All  other  classes , functions  and  outside  the  class

5) Who  can  use  private  instance  variable ?  ---> All  the  methods  of  same  class

6) Can  a  class  use  private  variable  of  a  different  class  object  directly ?  ---> No  becoz  it  is  not  visible
    Can  a  function  use  private  variable  of  the  object  directly ?  ---> No  becoz  it  is  not  visible
    Can  private  variable  of  the  object  be  used  directly  from  outside  the  class ?  ---> No  becoz  it  is  not  visible

7) How  to  use  private  variable  indirectly  ?  ---> obj . _classname__variablename

8) What  is  the  advantage  of  private  instance  variables  ?  --->  Data  hiding

9) What  is  data  hiding ?  --->  Data  of  the  object  is  hidden  from  other  classes , functions  and  outside  code

10) What  is  the  name  of  variable  password  and  why ?  --->
					__password  becoz  it  should  be  hidden  from  other  classes , functions  and  outside  the  class
      What  is  the  name  of  variable  balance ?  ---> __balance

11) In  other  words,  sensitive  data   should  be  private

12) Where  can  private  instance  variable  be  initialized ?  --->  Inside  method  of  same  class

13) What  happens  when  private  instance  variable  is  initalized  outside  the  class ?  --->  It  is  treated  as  public  variable  

14) Can  local  variable  name  be  __variable ?  --->  Yes  but  it  is  of  no  use  becoz  it  is  already  private  by  natute
								as  it  is  visible  to  single  function  (or)  method  where  the  variable  is  initialized

15) Can  global  variable  name  be  __variable ?  --->  Yes  but  it  is  of  no  use

16) In  other  words,  global  variable  is  visible  to  whole  program  even  when  name  starts  with  __

17) Let  object  contain  variables  __x  and  'y',
     What  does   object . __dict__   return ?  --->  {'_classname__x' : value , 'y' : value}
