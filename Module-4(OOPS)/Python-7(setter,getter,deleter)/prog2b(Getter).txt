getter  method
------------------
1) @property
    def  temp(self):
           return  something

2) What  is  the  name  of  getter  method ?  ---> Name  of  instance  variable 
     What  is  the  name  of  getter  method  if  instance  variable  name  is  temp ?  ---> temp  itself

3) What  is  the  decorator  to  define  a  getter  method ?  ---> @property  but  not  @instancevariablename . getter

4) How  many  arguments  can  a  getter  method  have ?  --->  No  arguments  apart  from  self

5) When  is  getter  method  executed ?  ---> As  soon  as  instance  variable  is  used

6) Which  of  the  following  execute  getter  method  ?
     a) print(obj . variable)  --->  Executes  getter  method  becoz  instance  variable  is  used
     b) obj . variable = 25 ---> Executes  setter  method  becoz  instance  variable  is  initilaized
     c) return  obj . variable --->   Executes  getter  method  becoz  instance  variable  is  used        
     d) 1.8 * obj . variable  + 32  --->  Executes  getter  method  becoz  instance  variable  is  used         
     e) print(variable)  --->  Not  executed  becoz  local  variable  is  being  used
     f) print(classname . variable)  ---> Not  executed  becoz  static  variable  is  being  used

7) What  does  getter  method  do ?  --->  Returns  value  of  2nd  variable  i.e.  obj . _temp

8) Where  is  the  value  returned  to ?  ---> obj . variable

9) What  does  getter  method  do  when  it  does  not  have  return  statement ?  --->  Returns  None  by  default

10) print(obj . variable) 
     What  is  printed  when  getter  method  does  not  have  return  statement ? --->  None

11) Can  class  have  getter  method  without  setter  method  ?  ---> No  becoz  they  form  a  pair

12) In  other  words,  getter  and  setter  methods  should  be  defined  together  becoz  they  form  a  pair

13) In  which  order  can  getter  and  setter  methods  defined ? ---> getter  followed  by  setter

14) Can  class  have  multiple  getter  methods ?  --->  Yes
										     i.e. One  for  each  instance  variable

15) Is  getter  method  executed  when  local , global  and  static  variables  are  being  used ?  ---> No

16) In  other  words,  getter  method  is  executed  only  when  instance  variable  is  being  used

17) Can  getter  method  be  called  explicitly ?  --->							
									No  and  it  is  automatically  executed  when  instance  variable  is  being  used
