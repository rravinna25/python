setter  method
------------------
1) @temp . setter
    def  temp(self , x):
              statements

2) What  does  setter  method  do ?  --->  Validates  the  value  of  instance  variable  to  be  assigned  

3) What  is  the  name  of  setter  method ?  --->  Name  of  instance  variable 
     What  is  the  name  of  setter  method  if  instance  variable  name  is  temp ?  ---> temp  itself

4) What  is  the  decorator  to  define  a  setter  method ?  --->  @Instancevariablename . setter
												       Eg: @temp . setter

5) How  many  arguments  can  a  setter  method  have  ?  --->  One  argument  apart  from  self

6) What  is  the  value  of  argument  of  setter  method  ?  ---> The  value  to  be  assigned  to  instance  variable

7) When  is  setter  method  executed ?  ---> As  soon  as  instance  variable  is  initialized

8) What  does  obj . variable = value  do ?  ---> Automatically  executes  setter  method  when  the  variable  has  a
									 setter  method  and  the  right  side  value  is  passed  to  setter  method

9) What  does  obj . temp = 37  do ?  ---> Executes  setter  method  of  temp  variable
											and
                                                                 37  is  passed  to  the  method

10) obj . variable = invalid-value
     What  does  setter  method  do ?  ---> Raises  an  error

11) obj . variable = valid-value
      What  does  setter  method  do ?  ---> Assigns  the  value  to  another  instance  variable  like  self . _temp 
								    in  view  of  getter  method

12) Can  class  have  setter  method  without  getter  method  ?  ---> No

13) In  which  order  can  getter  and  setter  methods  be  defined ?  ---> getter  followed  by  setter

14) Can  class  have  multiple  setter  methods ?  --->  Yes  i.e. One  for  each  instance  variable

15) Is  settter  method  executed  when  local , global  and  static  variables  are  initialized ?  ---> No

16) In  other  words,  setter  method  is  executed  only  when  instance  variable  is  initilaized

17) Can  setter  method  be  explicitly ?  --->  No  and  it  is  automatically  executed  as  soon  as  instance  variable 
									is  initilaized
