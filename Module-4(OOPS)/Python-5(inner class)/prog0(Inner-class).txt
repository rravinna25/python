Nesting  of  classes  (or)  Inner  class
-------------------------------------------
1) What  is  nesting  of  classes ?  ---> A  class  is  defined  in  another  class
							     Eg:  class  outer:
								           methods
								           class  inner:
									          methods
								           methods

2) Is  inner  class  visible  to  other  classes , functions  and  outside  the  class ?  --->  Yes

3) def  outer():
          def   inner():
	         pass
    Is  inner  function  visible  to  other  functions ,  classes  and  outside ?  ---> No

4) In  other  words,  inner  function  is  hidden  from  others  but  not  inner  classes

5) What  are  the  two  ways  to  create  inner class  object ?  --->          
     a) outerclassobject .  inner()
	 Eg:  o = outer()  --->  creates  outer  class  object
	        i = o . inner()  --->  creates  inner  class  object  wrt  outer  class  object
    b) outerclassname . inner()
        Eg:  i  =  outer . inner()   --->  creates  inner  class  object  thur  outer  class  name

6) o = outer()
     i = o . inner()
     How  to  reduce  the  two  statements  to  a  single  statement  ?  --->   i = outer() . inner()

7) i =  inner() 
    Is  the  statement valid ? --->  No  becoz  inner  class  object  can  not  be  created  without
					             outer  class  object  (or)  outer  class  name

8) There  is  a  strong  bonding  between  outer  class  and  inner  class

9) Where  can  inner  class  object  be  created ?  --->  
									Any  where  in  the  program  becoz  inner  class  is  visible  to  whole  program


Note:
1) class   university:
             class   department:
		                 ...
    There  can  not  be  university  without  department.
     If  university  is  closed, department  is  automatically  closed

2) class   car:
            class  engine:
                   ......
    There  can  not  be  a  car  without  engine.
