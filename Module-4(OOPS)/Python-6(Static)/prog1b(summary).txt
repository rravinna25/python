Summary
-----------
1) print(object . x)
    Which  variable  is  accessed ?  ---> Instance  variable  'x'  becoz  object  is  being  used

2) print(object . x)
    What  happens  when  object  does  not  have  instance  variable  'x' ?  ---> static  variable  'x'  is  accessed

3) print(object . x)
    What  happens  without  instance  and  static  variable  'x' ?  ---> Raises  error

4) print(classname . x)
    Which  variable  is  accessed ?  ---> Static  variable  becoz  classname  is  being  used

5) print(classname . x)
    What  happens  when  class  does  not  have  static  variable  'x' ?  ---> Raises  error

6) object . new-variable = value
    What  does  it  do ? --->  Adds  a  new  instance  variable  to  the  object  with  the  specified  value

7) object . valid-variable = value
    What  does  it  do  ? --->  Modifies  value  of  the  variable  in  the  object

8) classname . new-variable = value
    What  does  it  do ? ---> Adds  a  new  static  variable  to  the  class  with  the  specified  value

9) classname . valid-variable = value
    What  does  it  do ? ---> Modifies  value  of  static  variable

10) How  to  obtain  all  the  instance  variables  of  an  object ?  ---> object . __dict__

11) How  to  obtain  all  the  static  variables  of  a class ?  ---> classname . __dict__
